# nux (archiviert)

Alter, **eingestellter** Versuch (2023), das PHP-Legacy-CMS auf Deno zu portieren.
Vorläufer des aktuellen Ports in [`../qino/`](../qino/) — nicht mehr weiterentwickelt, nicht lauffähig.

Hier nur als Referenz/Ideenfundus aufbewahrt. Was davon eventuell übernommen werden
könnte, ist in [`../nux-inspiration.md`](../nux-inspiration.md) festgehalten.

> Veralteter Stand: nutzt z. B. `https://deno.land/std@0.93.0`, die alte
> `serve()`-Iterator-API und `Deno.bundle()`. Nicht als Vorlage für neuen Code verwenden.
